브라우저가 이미 잘하는 일을 다시 만들지 않는 carousel이다. 스와이프·관성·스냅은 전부
네이티브 스크롤이고 버튼·도트·키보드는 지원하는 브라우저에서 CSS가 직접 만든다.
스크립트는 그게 없는 브라우저에서만 같은 것을 채워 넣는다.

<Demo
  html={carousel('data-carousel data-carousel-counter class="gallery"', 10)}
  css={`.gallery {
  --carousel-items: 1.2;
  --carousel-gap: 0.75rem;
}`}
/>

## 무엇이 다른가

- **설정 표면이 CSS다.** 한 화면 아이템 수도, 간격도, 정렬도 CSS 변수다. 브레이크포인트는
  `@container`가 처리하고 JavaScript는 관여하지 않는다.
- **프레임워크 래퍼가 없다.** Vue·React·Angular용 패키지가 따로 없는 게 아니라 필요가 없다 —
  마크업과 CSS만 쓰므로 감쌀 프레임워크 종속 부분이 애초에 없다.
- **런타임 의존성 0.** 번들은 gzip 3.6KB이고 네이티브 경로에서는 그마저도 인덱스 추적과
  loop·autoplay 같은 선택 기능에만 쓰인다.

## 최소 사용법

```html
<div data-carousel>
  <ul data-carousel-scroller>
    <li>…</li>
  </ul>
</div>
```

```js
import 'snapstrip';
import 'snapstrip/carousel.css';
```

`data-carousel`이 붙은 요소는 자동으로 초기화된다. 나머지는 전부 선택이다 —
[설치](/snapstrip/guides/installation/)부터 보면 된다.

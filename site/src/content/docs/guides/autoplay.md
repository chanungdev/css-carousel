```html
<div data-carousel data-carousel-autoplay="4000">
  <ul data-carousel-scroller>
    <li>…</li>
  </ul>
</div>
```

값은 ms다. `loop`와 같이 쓰면 끝에서 되돌아오지 않고 계속 돈다.

## 언제 멈추는가

| 상황 | 동작 |
|---|---|
| 포인터를 올림 | 일시정지, 벗어나면 재개 |
| 키보드 포커스가 안으로 들어옴 | 일시정지, 나가면 재개 |
| 화면 밖으로 스크롤 / 탭 전환 | 일시정지, 돌아오면 재개 |
| 사용자가 직접 스크롤·스와이프 | **영구 정지** |

마지막 줄이 핵심이다. 사용자가 손으로 넘기기 시작했다는 건 자기가 보고 싶은 것을 찾고 있다는
뜻이고, 거기서 캐러셀이 제멋대로 움직이면 방해가 된다.

포커스 판정은 `:focus-visible`을 쓴다 — 마우스로 버튼을 눌렀을 때까지 "키보드 사용자"로
취급해 멈춰 버리면 클릭 한 번에 자동 넘김이 죽는다.

## 다시 시작하게 하려면

```html
<div
  data-carousel
  data-carousel-autoplay="4000"
  data-carousel-autoplay-resume="5000"
>
```

마지막 입력으로부터 5초가 지나면 다시 돈다. 이 속성을 생략하면 영구 정지가 기본이다.

## 접근성

자동으로 움직이는 콘텐츠는 멈출 수 있어야 한다(WCAG 2.2.2). 위의 정지 조건이 그 역할을
하지만, 5초 넘게 도는 캐러셀이라면 눈에 보이는 정지 버튼을 함께 두는 편이 낫다.
`carousel.destroy()`를 부르면 타이머가 정리된다.

8. marquee — carousel이 아니다

스크롤 컨테이너가 없어서 스와이프도, 스냅도, 도트도, 현재 아이템 개념도 없다. 순수 CSS 띠다. CSS는 DOM을 복제할 수 없으므로 사본은 마크업에서 직접 넣고 aria-hidden을 붙인다. hover하면 멈춘다.
